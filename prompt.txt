Ты — инженер-разработчик. Создай полноценный микросервис на Node.js/TypeScript, который состоит из двух частей:

Часть 1:

🎯 Назначение:
Принимает HTTP-запрос POST по адресу `/analyze` с JSON-данными:
{
  "имя_сайта": "example",
  "url_сайта": "https://example.com"
}

🧠 Поведение:
1. Использует библиотеку Playwright для автоматического анализа указанного сайта:
   - Определяет все визуальные и интерактивные элементы (кнопки, поля ввода, ссылки, формы, меню, карточки, анимации и т.д.).
   - Извлекает основные стили элементов (цвета, шрифты, размеры, border-radius, spacing, box-shadow, состояния hover/focus/active и т.п.).
   - Анализирует интерактивные элементы (раскрывающиеся блоки, анимацию, формы и поля ввода и т.д.).
   - Определяет повторяющиеся паттерны (например, одинаковые цвета кнопок → primary color, одинаковые тени → shadow token).
   - Активно вычленяет типовые блоки из популярных сетевых библиотек компонентов (shadcn/ui, reactbits, Bootstrap, Material-UI, Ant Design, Chakra UI и подобных) путём анализа CSS-классов, data-атрибутов, структуры DOM и характерных стилевых сигнатур этих библиотек.
   - Строит иерархию токенов, компонент и семантических значений по образцу JSON-файла `design-system-example.json` (при необходимости расширяя и добавляя элементы).

📁 Результат:
2. Формирует JSON-файл дизайн-системы, похожий по структуре на образец:
   - Читает шаблон `design-system-example.json` из корня проекта.
   - На основе анализа сайта подставляет извлечённые значения, при необходимости добавляет атрибуты.
   - Сохраняет результат в подкаталог `designs/<имя_сайта>/design-system.json`.

🛠️ Технические требования:
- Для браузерного анализа: Playwright (нативный npm пакет)
- Код должен быть модульным на TypeScript (src/server.ts, src/analyzer.ts, src/designGenerator.ts и т.д.)
- Используй Express.js для HTTP API
- Используй BullMQ с Redis для асинхронной обработки задач
- Добавь базовые проверки ошибок (некорректный URL, таймаут загрузки, ошибки парсинга, ошибки javascript, сообщения о защите от ботов и т.д.)
- Если сайт недоступен — вернуть JSON-ответ с ошибкой, предусмотри различные коды ошибок в ответах.
- Поддержи CORS для локальной отладки.
- Используй TypeScript для типобезопасности

📤 Пример запроса:
POST http://domain.local:3000/analyze
Body:
{
  "имя_сайта": "shopdemo",
  "url_сайта": "https://shopdemo.com"
}

📥 Пример ответа:
{
  "status": "ok",
  "path": "designs/shopdemo/design-system.json"
}

💡 Дополнительно:
- Разработай для этого проекта шелл-скрипт, запускаемый на хост машине и принимающий два параметра (имя сайта и url сайта).
- При анализе можешь использовать Playwright API: `page.$$('selector')`, `element.evaluate(() => window.getComputedStyle(el))`, `page.screenshot()` для извлечения визуальных свойств.
- Для структурирования токенов используй категории: colors, typography, spacing, radius, shadows, transitions, components.
- Playwright должен активно обнаруживать и вычленять типовые блоки из популярных библиотек компонентов (shadcn/ui, reactbits, Bootstrap, Material-UI, Ant Design, Chakra UI и подобных). Анализируй CSS-классы, data-атрибуты (например, `data-*`), структуру DOM и характерные стилевые паттерны для идентификации компонентов из этих библиотек. Указывай в дизайн-системе информацию о библиотеке-источнике для каждого обнаруженного компонента, включая название библиотеки и библиотечно-специфичные свойства или варианты компонента.
- Для генерации итогового JSON бери структуру из `design-system-example.json`, расширяй при необходимости, заполняй её реальными значениями.
- Реализуй логику объединения похожих цветов и стилей, чтобы сформировать минимально избыточную систему токенов.
- Дизайн-системы должны быть примонтированы в docker-контейнер как volume, чтобы сервис мог подхватывать их налету без пересборки контейнера.
- Если дизайн-система под указанным именем уже существует, повторный запрос с тем же именем должен полностью переписывать её.
- Код должен быть документирован.

Назначение:

- Позволяет в чате с ИИ в Cursor IDE писать что-то вроде "добавь на страницу блок XXX из дизайн-системы сайта YYY".
